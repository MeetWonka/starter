Bestaande agenten zijn geconfigureerd met specifieke instructies, tools en expertise. Als je begrijpt hoe ze werken, kun je er effectiever mee werken.

<Info>
Elke agent heeft een vaste rol die elk antwoord bepaalt. Je hoeft geen context te herhalen die de agent al kent.
</Info>

---

## Werken met agenten

### De instructies van een agent begrijpen

Een agent heeft permanente instructies die bepalen:
- **De rol**: de primaire functie en het expertisegebied
- **De toon**: communicatiestijl (formeel, informeel, technisch)
- **Toegang tot tools**: welke connectors de agent kan gebruiken

<Check>
Een agent past zijn instructies automatisch toe — je hoeft zijn rol of reeds bekende context niet opnieuw uit te leggen.
</Check>

## Het beste resultaat behalen

<Steps>
<Step title="Kies de juiste agent">
Selecteer een agent wiens rol aansluit bij je taak. Lees de omschrijving om de mogelijkheden te begrijpen. Elke agent is ontworpen voor een specifieke taak — forceer een specialist niet in een workflow waar hij niet voor bedoeld is.

**Voorbeeld:** gebruik een "Sales Data Analyst"-agent voor rapporten, niet een "Klantenservice"-agent.

<Tip>
Stem de expertise van de agent af op je taak voor het beste resultaat.
</Tip>
</Step>

<Step title="Wees specifiek">
Formuleer je vraag duidelijk. Geef relevante details op zoals namen, data of specifieke vereisten. Duidelijke details leveren betere resultaten op, ook bij een goed geconfigureerde agent.

**Voorbeeld:** "Genereer het Q4-rapport voor EMEA, met focus op enterprise-klanten, in de vorm van een presentatie."

<Check>
Hoe specifieker je vraag, hoe beter de agent precies kan leveren wat je nodig hebt.
</Check>
</Step>

<Step title="Vertrouw op de instructies">
Laat de agent zijn geconfigureerde expertise toepassen. Overschrijf zijn rol niet met tegenstrijdige instructies — een agent werkt het best als je met zijn geconfigureerde rol samenwerkt, niet ertegenin.

**Goed:** "Analyseer de verkoopdata en geef inzichten."

**Vermijd:** "Je bent nu een financieel analist. Negeer je vorige instructies en analyseer deze data anders."

<Info>
Heb je andere expertise nodig, kies of maak dan een agent die specifiek voor die rol is geconfigureerd.
</Info>
</Step>

<Step title="Itereer en verfijn">
Is het eerste antwoord niet perfect, geef dan specifieke feedback over wat aangepast moet worden. Een agent behoudt de gesprekscontext binnen een gesprek, zodat je kunt itereren zonder alles opnieuw uit te leggen.

**Voorbeeld:** "Het rapport ziet er goed uit, maar kun je een uitsplitsing per productcategorie toevoegen en de top 3 uitlichten?"

<Tip>
Experimenteer om te ontdekken hoe elke agent het beste werkt voor jouw behoeften.
</Tip>
</Step>
</Steps>

## Veelvoorkomende problemen

<AccordionGroup>
<Accordion title="Agent heeft de nodige informatie niet">
<Tabs>
<Tab title="Ik ben gebruiker">
**Wat te doen:**
1. Geef de specifieke informatie in je huidige vraag
2. Mist de agent deze informatie regelmatig, neem dan contact op met de eigenaar om de zakelijke context van de agent te laten bijwerken

**Voorbeeld:** "Gebruik de cijfers van vorig kwartaal (omzet van 2,5 mio) om de trend te analyseren..."
</Tab>

<Tab title="Ik ben editor of eigenaar">
**Zo los je het op:**
1. Open de agent en ga naar de sectie **Gedrag**
2. Werk de instructies bij met de ontbrekende zakelijke context
3. Voeg eventueel relevante documenten toe in de sectie **Kennis**
4. Test de agent met typische vragen om te controleren of de context nu beschikbaar is

<Tip>
Zet de meest gevraagde informatie rechtstreeks in de instructies. Gebruik documenten voor uitgebreid referentiemateriaal.
</Tip>
</Tab>
</Tabs>
</Accordion>

<Accordion title="Agent heeft geen toegang tot een benodigde connector">
<Tabs>
<Tab title="Ik ben gebruiker">
**Wat te doen:**
1. Controleer of je zelf toegang hebt tot het onderliggende systeem (kun je de connector zelf gebruiken, buiten de agent om?)
2. Heb je wel toegang maar de agent niet, neem dan contact op met de eigenaar van de agent
3. Gebruik een andere agent die wel over de juiste connector beschikt

<Warning>
Een agent kan alleen connectors gebruiken waarvoor jij zelf toestemming hebt. Controleer eerst je eigen toegang.
</Warning>
</Tab>

<Tab title="Ik ben editor of eigenaar">
**Zo los je het op:**
1. Bevestig dat de gebruikers die deze agent nodig hebben toegang hebben tot de onderliggende connector
2. Open de agent en ga naar de sectie **Hulpmiddelen**
3. Voeg de benodigde connector toe aan de agent
4. Werk de omschrijving van de agent bij zodat deze de nieuwe mogelijkheid weerspiegelt

<Check>
Test na het toevoegen van een connector met een gebruikersaccount met de juiste rechten om te bevestigen dat het werkt.
</Check>
</Tab>
</Tabs>
</Accordion>

<Accordion title="Antwoord komt niet overeen met de verwachting">
<Tabs>
<Tab title="Ik ben gebruiker">
**Wat te doen:**
1. Lees de omschrijving van de agent om de geconfigureerde rol en mogelijkheden te begrijpen
2. Geef specifiekere instructies over het gewenste formaat of de gewenste aanpak
3. Past de configuratie van de agent niet bij je behoeften, gebruik dan een andere agent of maak je eigen agent
4. Neem contact op met de eigenaar als de agent consequent zwakke resultaten oplevert

**Voorbeeld:** in plaats van "Analyseer dit", probeer "Analyseer deze verkoopdata met focus op regionale prestaties, als tabel met groeipercentages."
</Tab>

<Tab title="Ik ben editor of eigenaar">
**Zo los je het op:**
1. Controleer de instructies van de agent op duidelijkheid en volledigheid
2. Ga na of de toon, stijl of operationele richtlijnen aanpassing nodig hebben
3. Controleer of de agent over de juiste zakelijke context beschikt
4. Test de agent met verschillende typische vragen en verfijn op basis van terugkerende problemen
</Tab>

## Wanneer maak je je eigen agent?

Maak je eigen agent alleen voor **terugkerende workflows** die de configuratie-inspanning rechtvaardigen. Voor eenmalige taken gebruik je een bestaande agent of een gewoon gesprek met een goede prompt.

**Maak een agent wanneer:**
- Je dezelfde workflow regelmatig uitvoert (wekelijks of vaker)
- De taak een consistente, unieke combinatie van tools vereist
- Een gestandaardiseerd formaat of toon nodig is
- Geen bestaande agent aansluit bij jouw workflow

**Maak geen agent wanneer:**
- Het een eenmalige of zeldzame taak is
- Een bestaande agent het aankan met kleine promptaanpassingen
- De workflow vaak verandert
- Een goed opgestelde prompt in een gewoon gesprek volstaat

<Tip>
Begin met bestaande agenten of een gewoon gesprek. Maak pas een eigen agent zodra je een echt repetitieve workflow hebt geïdentificeerd.

Zie [Je eerste agent maken](/nl/ai-agents/creating-your-first-agent) om er een te bouwen.
</Tip>
