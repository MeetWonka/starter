## Comment lire cette page

- **Vitesse** : rapidité de réponse du modèle, de ● (lent) à ●●●●● (très rapide).
- **Coût** : crédits consommés par rapport aux autres modèles, de € (le moins cher) à €€€€ (le plus cher). Voir [Usage IA et crédits](/fr/pricing/tokens-guide) pour le fonctionnement des crédits.
- **Région** : où le modèle s'exécute. 🇪🇺 UE reste dans l'Union européenne, 🇺🇸 US s'exécute aux États-Unis, 🌐 Global peut s'exécuter dans n'importe quelle région du fournisseur.
- **Raisonnement** : le modèle réfléchit étape par étape avant de répondre. Nécessaire pour les outils métier connectés (ERP, CRM, e-mail).
- **Fenêtre de contexte** : quantité de texte que le modèle peut lire d'un coup (1M de tokens représente environ 700 000 mots).
