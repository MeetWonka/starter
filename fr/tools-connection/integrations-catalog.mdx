## Connexion en un clic

Le mode le plus simple. WonkaChat vous envoie vers la page de connexion officielle de l'outil, vous vous connectez avec votre compte habituel et vous acceptez l'accès. WonkaChat ne voit jamais votre mot de passe.

1. Allez dans **Personnaliser → Connecteurs** et ouvrez l'intégration.
2. Cliquez sur **Se connecter**. Une fenêtre de connexion de l'outil s'ouvre.
3. Connectez-vous avec votre compte habituel et acceptez les accès demandés.
4. Vous revenez automatiquement dans WonkaChat : l'intégration apparaît comme connectée.

## Clé API

Certains outils ne proposent pas de connexion pour les applications tierces. À la place, vous créez une **clé API** (un long code secret) dans l'outil et vous la collez une fois dans WonkaChat.

1. Dans l'outil, créez une clé API (voir le tableau ci-dessous pour savoir où la trouver).
2. Dans WonkaChat, allez dans **Personnaliser → Connecteurs**, ouvrez l'intégration et cliquez sur **Se connecter**.
3. Collez la clé dans le formulaire sécurisé qui s'ouvre, puis validez.

<Warning>Une clé API donne accès à votre compte : ne la partagez jamais dans une conversation. Collez-la uniquement dans le formulaire de connexion. En cas de fuite, supprimez-la dans l'outil et créez-en une nouvelle.</Warning>

## Informations de votre outil

Ces intégrations sont hébergées par Wonka AI et se connectent à **votre propre instance** de l'outil. WonkaChat a besoin de savoir où se trouve votre instance et quel compte utiliser.

1. Rassemblez les informations listées dans le tableau ci-dessous pour votre outil.
2. Dans WonkaChat, allez dans **Personnaliser → Connecteurs**, ouvrez l'intégration et cliquez sur **Se connecter**.
3. Remplissez chaque champ et enregistrez. WonkaChat vérifie la connexion immédiatement.

<Tip>Vos informations sont stockées chiffrées et utilisées uniquement pour vos propres demandes.</Tip>

| Intégration | Champs à remplir |
|---|---|
| <img src="https://stwonkachatpweu001.blob.core.windows.net/mcp-logo/brezzeway.png" alt="" width="20" height="20" noZoom className="inline m-0" /> **Breezeway** | Client ID, Client Secret |
| <img src="https://stwonkachatpweu001.blob.core.windows.net/mcp-logo/hostaway.png" alt="" width="20" height="20" noZoom className="inline m-0" /> **Hostaway** | Identifiant de compte (Account ID), Clé API |

## Votre outil n'est pas dans la liste ?

Si votre outil propose un serveur MCP, un administrateur peut l'ajouter comme [connecteur personnalisé](/fr/tools-connection/custom-connectors) en quelques minutes.

Sinon, demandez-le-nous depuis la page [Obtenir de l'aide](/fr/support-resources/getting-help) : de nouvelles intégrations sont ajoutées chaque semaine.

<Info>La connexion échoue ou l'intégration ne répond plus ? Consultez [Dépannage des connexions](/fr/tools-connection/troubleshooting-connections).</Info>
