Chaque fois que vous envoyez un message à WonkaChat ou à un agent, un modèle IA lit votre demande et rédige une réponse. Ce travail se mesure en **tokens**. La facturation des tokens dépend de votre forfait.

## Qu'est-ce qu'un token ?

Les tokens sont l'unité de mesure de l'usage d'un modèle IA. Votre question et la réponse de l'IA consomment toutes deux des tokens.

- 1 token ≈ 3/4 d'un mot en anglais (un peu moins en français)
- « Bonjour, comment allez-vous ? » ≈ 8 tokens
- Un e-mail type (200 mots) ≈ 300 tokens
- Une page complète (500 mots) ≈ 750 tokens

Les fichiers, les longues conversations et les résultats d'outils (par exemple une recherche web ou une application connectée) ajoutent aussi des tokens, car le modèle doit les lire.

## Pourquoi certains modèles consomment plus de crédits

Les modèles IA ont des tailles différentes. Les plus grands raisonnent mieux sur les tâches complexes, mais chaque token coûte plus cher.

| Taille du modèle | Adapté pour | Coût relatif |
| --- | --- | --- |
| Rapide / petit | Questions simples, classification, résumés courts, gros volumes | Faible |
| Standard | E-mails, rapports, recherche, la plupart des tâches quotidiennes | Moyen |
| Avancé / raisonnement | Analyse complexe, stratégie, code, décisions critiques | Élevé |

Les modèles disponibles sont listés dans le sélecteur de modèle de WonkaChat. Votre administrateur décide quels modèles votre organisation peut utiliser.

## Conseils pour bien utiliser vos crédits

- **Commencez avec un modèle standard.** Passez à un modèle avancé seulement si la qualité ne suffit pas.
- **Ouvrez une nouvelle conversation pour un nouveau sujet.** Une longue conversation rend chaque nouveau message plus coûteux, car le modèle relit tout l'historique.
- **Joignez uniquement les fichiers utiles.** Chaque document joint est lu par le modèle.
- **Donnez à chaque agent le bon modèle.** Un agent FAQ simple n'a pas besoin du modèle le plus avancé.

## Questions fréquentes

<Accordion title="Puis-je changer de modèle ?" icon="shuffle">
Oui. Vous pouvez choisir un modèle pour chaque conversation, et chaque agent peut utiliser un modèle différent. Changer de modèle n'entraîne aucune pénalité.
</Accordion>

<Accordion title="Comment savoir quel modèle j'utilise ?" icon="circle-question">
Le modèle actuel est affiché dans le sélecteur de modèle en haut de la conversation. Pour un agent, le modèle se règle dans les paramètres de l'agent.
</Accordion>
