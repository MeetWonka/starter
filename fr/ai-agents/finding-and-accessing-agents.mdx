Les agents se trouvent dans la section **Agents** de votre barre latérale. Vous y parcourez tous les agents que vous pouvez utiliser, démarrez une conversation ou en créez un nouveau.

---

## La section Agents de la barre latérale

Ouvrez **Agents** dans la barre latérale pour afficher :

- **Tous les agents** — ouvre la bibliothèque complète des agents (`/agents`)
- **Nouvel agent** — démarre le parcours de création guidée
- **Agents épinglés** — les agents que vous avez mis en favoris
- **Agents récents** — les agents que vous avez utilisés récemment

<Tip>
Cliquez sur un agent épinglé ou récent pour démarrer immédiatement une nouvelle conversation avec lui.
</Tip>

---

## La bibliothèque d'agents (Tous les agents)

La bibliothèque organise tous les agents que vous pouvez utiliser avec des onglets de filtrage :

| Onglet | Affiche |
|--------|---------|
| **Tout** | Tous les agents que vous pouvez utiliser |
| **Les miens** | Les agents que vous avez créés |
| **Favoris** | Les agents que vous avez épinglés |
| **Partagés avec moi** | Les agents que d'autres ont partagés avec vous |
| **Organisation** | Tous les agents partagés à l'échelle de l'organisation (administrateurs uniquement) |

Utilisez le champ de recherche et les filtres par tags pour affiner la liste, et triez par nom, propriétaire, modèle ou dernière utilisation.

**Fonctionnalités :**
- Parcourir et filtrer les agents par onglet
- Rechercher par nom ou description
- Trier et filtrer avec des tags
- Ouvrir **Parcourir les templates** pour partir d'un modèle prêt à l'emploi plutôt que d'un agent vierge

Vous pouvez invoquer n'importe quel agent auquel vous avez accès directement depuis une conversation, en tapant `@` suivi de son nom.
