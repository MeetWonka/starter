## Hosting and infrastructure

- **Hosting**: Microsoft Azure West Europe by default, with EU-based infrastructure and data residency controls.
- **CDN**: Cloudflare for content delivery and edge routing.
- **Encryption**: TLS 1.2 or higher in transit, AES-256 at rest.

## Security testing and audits

- **Penetration testing**: annual independent (external black-box) penetration test.
- **Independent security audits**: periodic third-party information security audits.
- **Sub-processors**: annual security reviews of sub-processors.
- **Monitoring**: continuous monitoring and incident response procedures.

## Access and authentication

- **Single sign-on**: OIDC (Microsoft, Google, or a custom provider) or SAML, with the option to require SSO for non-admin users.
- **Multi-factor authentication**: available for every account.
- **Role-based access control**: organization roles, sharing permissions (Viewer / Editor / Owner), groups and tool policies — see [Access control](/en/security-governance/access-control).
- **RBAC audit log**: a record of permission and tool-policy changes, for accountability.

## Model regions

WonkaChat reaches AI models through an AI gateway that connects to several providers — Microsoft Azure, Google Vertex AI, Mistral and others — each hosting models in a specific region.

- Most models run in the **EU**.
- Some models run in the **US**.
- Some are reached through a **global** endpoint that isn't tied to one region.

The model selector shows a region badge (EU, US or global) next to each model, so you can see where a model runs before you use it. **Data you send to a model is processed in that model's region.** If your organization needs to keep AI usage within the EU, ask your administrator to restrict available models to EU-hosted ones — see [Groups and tool policies](/en/administration/groups-and-tool-policies).

<Note>
WonkaChat itself — your conversations, files, agents and organization data — is hosted in Microsoft Azure West Europe regardless of which model you use. Model region applies only to the message you send to that model for processing.
</Note>
