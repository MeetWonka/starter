Agents live in the **Agents** section of your sidebar. From there you can browse every agent you can use, start a conversation, or create a new one.

---

## The Agents Sidebar Section

Open **Agents** in the sidebar to reveal:

- **All agents** — opens the full agent library at `/agents`
- **New agent** — starts the guided agent creation flow
- **Pinned agents** — agents you've starred for quick access
- **Recent agents** — agents you've used recently

<Tip>
Click an agent under Pinned or Recent to start a new conversation with it immediately.
</Tip>

---

## The Agent Library (All Agents)

The agent library organizes every agent you can use with scope tabs at the top:

| Scope | Shows |
|-------|-------|
| **All** | Every agent you can use |
| **Mine** | Agents you created |
| **Favorites** | Agents you've pinned |
| **Shared with me** | Agents others shared with you |
| **Organization** | All organization-wide agents (administrators only) |

Use the search field and tag filters to narrow down the list, and sort by name, owner, model, or last used.

**Features:**
- Browse and filter agents by scope
- Search by name or description
- Sort and filter with tags
- Open **Browse templates** to start from a pre-built template instead of a blank agent

You can invoke any agent you have access to directly from a conversation by typing `@` followed by its name.
