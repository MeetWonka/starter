## One-click sign-in

The simplest mode. WonkaChat sends you to the official sign-in page of the tool, you sign in with your usual account and accept the access. WonkaChat never sees your password.

1. Go to **Customize → Connectors** and open the integration.
2. Click **Connect**. A sign-in window for the tool opens.
3. Sign in with your usual account and accept the requested access.
4. You come back to WonkaChat automatically: the integration shows as connected.

## API key

Some tools do not offer sign-in for third-party apps. Instead, you create an **API key** (a long secret code) in the tool and paste it once in WonkaChat.

1. In the tool, create an API key (see the table below for where to find it).
2. In WonkaChat, go to **Customize → Connectors**, open the integration and click **Connect**.
3. Paste the key in the secure form that opens, then confirm.

<Warning>An API key gives access to your account: never share it in a conversation. Only paste it in the connection form. If it leaks, delete it in the tool and create a new one.</Warning>

## Your tool's details

These integrations are hosted by Wonka AI and connect to **your own instance** of the tool. WonkaChat needs to know where your instance is and which account to use.

1. Gather the details listed in the table below for your tool.
2. In WonkaChat, go to **Customize → Connectors**, open the integration and click **Connect**.
3. Fill in each field and save. WonkaChat checks the connection right away.

<Tip>Your details are stored encrypted and only used for your own requests.</Tip>

| Integration | Fields to fill in |
|---|---|
| <img src="https://stwonkachatpweu001.blob.core.windows.net/mcp-logo/brezzeway.png" alt="" width="20" height="20" noZoom className="inline m-0" /> **Breezeway** | Client ID, Client Secret |
| <img src="https://stwonkachatpweu001.blob.core.windows.net/mcp-logo/hostaway.png" alt="" width="20" height="20" noZoom className="inline m-0" /> **Hostaway** | Account ID, API Key |
