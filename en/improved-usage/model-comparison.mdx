## How to read this page

- **Speed**: how fast the model answers, from ● (slow) to ●●●●● (very fast).
- **Cost**: how many credits the model uses compared with the others, from € (lowest) to €€€€ (highest). See [AI usage and credits](/en/pricing/tokens-guide) for how credits work.
- **Region**: where the model runs. 🇪🇺 EU stays in the European Union, 🇺🇸 US runs in the United States, 🌐 Global can run in any region of the provider.
- **Reasoning**: the model thinks step by step before answering. Needed for connected business tools (ERP, CRM, email).
- **Context window**: how much text the model can read at once (1M tokens is roughly 750,000 words).
