---
title: "Artifacts"
description: "Interactive content agents can build for you: documents, code, and richer answer blocks like forms and charts."
---

**Artifacts** are pieces of content an agent creates alongside its answer — a document, a piece of code, a chart — that you can view, interact with, and export, instead of reading everything as plain chat text. Some agents can also respond with richer interactive blocks: a clarifying question, a fillable form, a chart, or an email draft.

<Info>
Artifacts depend on the agent you're talking to. If an agent never shows them, its builder hasn't enabled the capability, or your organization has turned it off.
</Info>

---

## Viewing an Artifact

When an agent generates an artifact, it appears as a card in the conversation — **Click to open**. Opening it shows the full content in a dedicated panel next to the chat, so you can keep reading the conversation while reviewing what was built.

While an artifact is being generated, you'll see a live "Creation of…" indicator; once it's done, the card confirms it was generated.

## Branded Design Templates

If an agent builder has enabled **Design** for an agent, that agent can generate documents (Word, PowerPoint, Excel) that follow your organization's branded templates — fonts, colors, logos, and layout — instead of a generic look. This is set up by uploading template files and brand assets when building the agent; as an end user, you don't need to do anything differently, the agent applies the template automatically when generating a document.

## Interactive Answer Blocks

Beyond documents and code, some agents can answer using interactive blocks instead of plain text:

<CardGroup cols={2}>
<Card title="Questions" icon="circle-question">
Instead of asking a clarifying question in plain text, the agent shows an interactive prompt you respond to directly.
</Card>
<Card title="Forms" icon="list-check">
The agent presents a fillable form to collect several pieces of information at once, rather than asking one by one.
</Card>
<Card title="Charts" icon="chart-column">
Data the agent produces can render as an interactive chart instead of a table or plain numbers.
</Card>
<Card title="Email" icon="envelope">
The agent can draft an email in a dedicated block you can review before sending or copying.
</Card>
</CardGroup>

These blocks appear only when the agent you're using has them enabled — they're configured per agent by its builder.

<Note>
If you expect a form or chart and only get plain text back, the agent's builder likely hasn't turned that capability on for this agent.
</Note>
