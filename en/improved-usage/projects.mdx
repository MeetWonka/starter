---
title: "Projects"
description: "Group related chats together and keep the assistant's memory scoped to just one piece of work."
---

**Projects** let you group related chats so you can pick up a piece of work in one place, instead of hunting through your full chat history. Each project is personal to you — it's not shared with teammates the way agents or skills can be.

<Info>
Projects are an optional organization feature. If you don't see **Projects** in your sidebar, ask your administrator to enable it.
</Info>

---

## Creating a Project

<Steps>
<Step title="Open the Conversations section">
In the sidebar, expand **Conversations**, then find **Projects**.
</Step>
<Step title="Start a new project">
Click **New project**.
</Step>
<Step title="Name it">
Enter a **Project name** and confirm with **Create project**.
</Step>
</Steps>

## Adding Chats to a Project

<Steps>
<Step title="Open a chat's options">
Hover a conversation in your history and open its options menu (the **⋯** icon).
</Step>
<Step title="Change project">
Select **Change project**, then pick the project to assign this chat to.
</Step>
</Steps>

To remove a chat from a project, open the same options menu and select **Remove from project**.

<Tip>
You can also start a new chat directly from inside a project — it's assigned to that project automatically.
</Tip>

## Managing Projects

From the **Projects** list in your sidebar, you can:
- **Pin** a project to keep it near the top
- **Rename** a project
- **Delete** a project (this doesn't delete the chats inside it — they simply become unassigned)

## Project-Scoped Memory

When Memories is enabled for your organization, anything the assistant remembers can be scoped to a single project instead of applying everywhere. While working inside a project, choose **This project** as the memory scope instead of the default **User** scope.

This keeps context from one piece of work — client names, project-specific decisions, terminology — from leaking into unrelated conversations. See [Memories](/en/improved-usage/memories) for how scoped memory works.

<Note>
Project memory is still personal to you. It isn't shared with teammates who might also have access to the same project's chats.
</Note>
